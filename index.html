Every chaotic network is a lock. Every controller is a key. Cut a key, turn it, and see whether the response system falls into step with the drive. Under the hood

The simulations use the Adams–Bashforth–Moulton predictor–corrector scheme (Diethelm, Ford, Freed, 2002) for the Caputo derivative. With a Caputo derivative, the response remembers its own starting state, so the numerical error can level off above tolerance if the drive and response start far apart or h is large; initial states are selected so that every default key synchronizes at default h. A lock counts as open when the error norm stays below 0.01 for the rest of the run. Settling times are measured on these numerical runs and are not analytical bounds.

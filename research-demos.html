1. Fractional Sliding Surface in Quaternion Field

Without decoupling into real subsystems, the quaternion sliding manifold is constructed directly as:

σr(t) = εr(t) + γr C0Itα [ [εr(t)] ‖εr(t)‖2μ ]

where [εr] = sign(εrR) + i sign(εrI) + j sign(εrJ) + k sign(εrK). On the sliding surface σr(t) = 0:

C0Dtα εr(t) = −γr [εr(t)] ‖εr(t)‖2μ

2. Sliding Mode Control Protocol

Under control law (13):

Ur(t) = −kr εr(t) − γr [εr(t)] ‖εr(t)‖2μ − lr [σr(t)] ‖σr(t)‖2ν

with μ = ν = 0.7, kr = 16, lr = 5, γr = 5, the error trajectories reach the surface in time tσ and vanish at tε = 0.78s.

1. Coupled STM–LTM Quaternion Dynamics

Short-term memory (STM, rq) and long-term memory (LTM, Hq) interact bi-directionally on fractional time scale β = 0.97. Projective synchronization error with scaling vector γ = [γ1, γ2] is:

ωq(τ) = θq(τ) − γq rq(τ),   ϖq(τ) = Wq(τ) − γq Hq(τ)

2. Adaptive Laws (AAPS) vs Finite-Time Laws (FTPS)

AAPS: Autonomous parameter updates without overestimating control gains:

CDβ λq(τ) = ‖ωq(τ)‖2,   CDβ δq(τ) = ‖ϖq(τ)‖2

FTPS: Fractional non-smooth reaching laws enforce finite-time stability:

u2q = −ε ηq ωq − ε ωq ‖ωq‖2(μ−1)},   k2q = −νq ϖq − ϖq ‖ϖq‖2(μ−1)}

1. First-Order Variable Substitution

Inertial networks feature second-order fractional derivatives CDα(CDα xρ). Defining intermediate velocity states:

σρ(ς) = CDα xρ(ς) + θρ xρ(ς),   ωρ(ς) = CDα yρ(ς) + θρ yρ(ς)

transforms the system into 16 coupled 1st-order equations with cross-coupling:

CDα σρ = −(aρ − θρ)σρ − (cρ − (aρ − θρ)θρ)xρ + ∑ (bρϱ + Δbρϱ)fϱ(xϱ)

2. Mittag–Leffler & Adaptive Control Laws

MLPS Law (Eq. 13): uρ = −lρ zρ + kρ eρ + ucomp, yielding exponential-type Mittag–Leffler decay ‖e(ς)‖ + ‖z(ς)‖ ≤ N ‖e(0) + z(0)‖ Eα(−πςα).

AAPS Law (Eq. 21): uρ = −(lρ(ς) + l̂ρ) zρ + k̂ρ eρ + ucomp with CDα lρ = ‖zρ‖2.

3. Synchronization Theorems & Invariance (EPJ Plus 140)

Theorem 1 (MLPS Mittag–Leffler Synchronization): Satisfied when feedback gains ensure Λ = max{Λ₁, Λ₂} < 0. Error norms decay bounded by Mittag–Leffler function Eα(−πςα).

Theorem 2 (AAPS Adaptive Synchronization): Autonomous tuning of velocity feedback gains guarantees asymptotic convergence without knowledge of uncertainty bounds.
